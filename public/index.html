How it works

Install skill. Run CLI. Ship demo videos.

One skill gives your agent everything it needs to go from zero to a live video demo gallery — prompts, API calls, and landing page all included.

01

Install the skill

Run npx skills add moose-lab/landing-page-marketing-skills. Drops into .claude/skills/ and Claude Code picks it up instantly — no config needed.

02

Tell Claude to generate demos

Say "generate video demos for my landing page." Claude reads the skill, picks scenes, writes prompts, and runs the CLI — fully autonomous.

03

Kling 3.0 renders the scenes

The CLI submits multi-shot payloads to Kling 3.0 Omni via PiAPI. Each scene has fine-tuned prompts, durations, aspect ratio, and native audio.

04

Gallery live on your page

Video URLs are saved to a manifest JSON. The Node.js server reads it and renders a filterable gallery automatically at localhost:3000.
