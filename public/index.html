How it works

Install. Generate. Ship.

One skill gives your agent everything it needs — prompts, API calls, and gallery page included.

01

Install the skill

Run npx skills add moose-lab/landing-page-marketing-skills. Claude Code picks it up instantly.

02

Tell Claude to generate

Say "generate video demos." Claude picks scenes, writes prompts, runs the CLI autonomously.

03

Kling 3.0 renders

Multi-prompt payloads submitted to Kling 3.0 API. Each scene: fine-tuned prompts, durations, native audio.

04

Gallery goes live

Videos saved to manifest JSON. Node.js server renders a filterable gallery with reproducible prompts.
