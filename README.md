# videoskills

> CLI tool to generate multi-scene AI video demos with **Kling 3.0** and serve them on a Node.js landing page.

Inspired by [marketingskills](https://github.com/coreyhaines31/marketingskills) — but for AI video demo generation and showcase.

---

## Quick Start

```bash
# Install dependencies
npm install

# Set your PiAPI key
export PIAPI_KEY=your_key_here

# See available scene types
npm run list

# Dry run (no API calls, just print payloads)
npm run generate:dry

# Generate all demos
npm run generate

# Start landing page
npm run serve
# → http://localhost:3000
```

---

## CLI Commands

```bash
# Generate demos for specific scenes
node cli/index.js generate-demo --model kling3 --scenes product_showcase,cinematic_landscape

# Generate all scenes
node cli/index.js generate-demo --model kling3 --scenes all

# Dry run (inspect prompts/settings without API)
node cli/index.js generate-demo --model kling3 --dry-run

# Check task status
node cli/index.js status --task-id <task_id>

# List available scenes
node cli/index.js list-scenes --model kling3
```

## How It Works

```
skills/kling3/
  SKILL.md              ← AI agent skill definition
  scene-presets.json    ← Scene configs + prompts

cli/
  index.js              ← CLI entry point
  commands/
    generate-demo.js    ← Main generate command
    list-scenes.js      ← List scenes command
    status.js           ← Poll task status
  lib/
    kling-api.js        ← PiAPI Kling 3.0 wrapper
    presets.js          ← Load scene presets
    manifest.js         ← Write demo manifest JSON

landing/
  server.js             ← Node.js static + API server

public/
  index.html            ← Demo gallery page
  demos/
    kling3-demos.json   ← Generated by CLI (auto-created)
```

**Flow:**
1. CLI reads `scene-presets.json` for the selected model
2. Builds API payloads (single-shot or multi-shot) per scene
3. Submits to PiAPI Kling 3.0 endpoint, polls for completion
4. Saves `public/demos/kling3-demos.json` manifest with video URLs
5. Landing page reads the manifest and renders a filterable gallery

---

## Adding a New Model

1. Create `skills/<model>/scene-presets.json` with your scenes
2. Create `skills/<model>/SKILL.md` with the agent guidance
3. Register the path in `cli/lib/presets.js`
4. Run: `node cli/index.js generate-demo --model <model>`

---

## API Provider

Default: **[PiAPI](https://piapi.ai)** (`api.piapi.ai`)

Set `PIAPI_KEY` env var. You can swap to any Kling-compatible provider by editing `cli/lib/kling-api.js`.
