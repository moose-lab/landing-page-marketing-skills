# videoskills

> CLI + AI agent skill to generate multi-scene AI video demos with **Kling 3.0** via **WaveSpeed.ai** and serve them on a landing page with a filterable gallery.

---

## Quick Start

```bash
# Install dependencies
npm install

# Set your WaveSpeed API key (get one at https://wavespeed.ai/accesskey)
cp .env.example .env
# Edit .env and add your key, then:
export WAVESPEED_API_KEY=your_key_here

# See available scene types
npm run list

# Dry run (no API calls, just print payloads)
npm run generate:dry

# Generate all demos
npm run generate

# Start landing page with video gallery
npm run serve
# → http://localhost:3000
```

### API Key Setup

1. Sign up at [wavespeed.ai](https://wavespeed.ai)
2. Go to [wavespeed.ai/accesskey](https://wavespeed.ai/accesskey) to get your API key
3. Copy `.env.example` to `.env` and paste your key:
   ```
   WAVESPEED_API_KEY=your_key_here
   ```
4. Or export directly: `export WAVESPEED_API_KEY=your_key_here`

> **Important:** Never commit `.env` to git. It's already in `.gitignore`.

## CLI Commands

```bash
# Generate demos for specific scenes
node cli/index.js generate-demo --model kling3 --scenes product_showcase,cinematic_landscape

# Generate all scenes
node cli/index.js generate-demo --model kling3 --scenes all

# Use custom presets (agent-generated)
node cli/index.js generate-demo --model kling3 --custom-presets ./my-presets.json

# Dry run (inspect prompts/settings without API)
node cli/index.js generate-demo --model kling3 --dry-run

# Check task status
node cli/index.js status --task-id <task_id>

# List available scenes
node cli/index.js list-scenes --model kling3

# Update skills from remote
node cli/index.js update-skills
```

## How It Works

```
skills/kling3/
  SKILL.md              ← AI agent skill definition (full automation workflow)
  scene-presets.json    ← Scene configs + prompts + WaveSpeed model mapping

cli/
  index.js              ← CLI entry point
  commands/
    generate-demo.js    ← Main generate command (supports --custom-presets)
    list-scenes.js      ← List scenes command
    status.js           ← Poll task status
    update-skills.js    ← Pull latest skill definitions
  lib/
    wavespeed-api.js    ← WaveSpeed.ai API wrapper
    presets.js          ← Load scene presets (built-in or custom path)
    manifest.js         ← Write demo manifest JSON (includes prompts)

landing/
  server.js             ← Node.js static + API server

public/
  index.html            ← Landing page + video gallery
  demos/
    kling3-demos.json   ← Generated by CLI (auto-created)
```

**Flow:**
1. Claude (or user) reads SKILL.md → selects scenes → customizes prompts
2. CLI reads presets, builds WaveSpeed API payloads per scene
3. Submits to WaveSpeed.ai endpoint, polls for completion
4. Saves `public/demos/kling3-demos.json` manifest with video URLs + prompts
5. Landing page gallery fetches manifest and renders video cards with prompts

## Agent Automation (Claude Code)

Tell Claude:
> "Generate video demos for my SaaS landing page"

Claude will:
1. Read SKILL.md to understand capabilities
2. Select appropriate scene types for your product
3. Customize prompts with your product details
4. Write a custom presets file
5. Run the CLI with `--custom-presets`
6. Serve the gallery and verify results

## Adding Custom Scenes

Edit `skills/kling3/scene-presets.json`:
```json
"my_custom_scene": {
  "label": "My Scene",
  "description": "What it's for",
  "settings": {
    "aspect_ratio": "16:9",
    "duration": 8,
    "sound": false,
    "cfg_scale": 0.5
  },
  "model_tier": "pro",
  "multi_prompt": [
    { "prompt": "Shot 1 description...", "duration": 4 },
    { "prompt": "Shot 2 description...", "duration": 4 }
  ]
}
```
